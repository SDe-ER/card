## 1. Version Overview

Equipment materials, phase 1 (Owner plan 2026-10-19): the operator named on a machine asks for its
parts, consumables and tools; the site supervisor reviews and consolidates what was asked;
management approves; the approved lines become **standard ERPNext Material Requests** carrying the
item, project, cost center and the Card Equipment accounting dimension. Buying and stock then run
in ERPNext. Returnable tools are tracked as **employee custody** in one shared custody store.
CARD writes no GL entry, no salary deduction and no HR violation.

## 3. Added — Verified

- **Operator page `/equipment-needs`** (phone width, the operator's own Frappe account): pick one of
  his machines (named as its operator, or on its monthly card this month), add parts/consumables or
  tools with quantity and reason, send; see his recent requests and their status. Server-rendered,
  translated (Arabic RTL, English LTR, Bengali, Hindi, Urdu). Verified with a real browser login on
  the dev site.
- **Equipment Needs Request**: one request per machine; project from the machine's open assignment;
  operator, "entered by" and "on behalf" kept; an item asked again for the same machine within the
  Settings window (default 30 days) is flagged for review only.
- **Equipment Needs Review** (Card Supervisor): *Get requests* pulls the project's submitted pending
  lines (no line twice, no line in two reviews); the requested quantity stays as asked; found on
  site, approved quantity, inspection, route (from store / buy for the project) and warehouse per
  line, with stock on hand.
- **Management approval** (Card Manager or System Manager, who also needs ERPNext's right to create
  Material Requests): draft Material Requests — Purchase, Material Issue, or Material Transfer to the
  tool custody store — each row with item, project, cost center and (parts) the Card Equipment
  dimension. ERPNext's own *Make Stock Entry* keeps project and equipment.
- **Employee Tool Custody**: handover, return, transfer, loss, damage; balances per worker; draft
  Stock Entries for the stock team; fixed-asset tools stay on the ERPNext Asset (custodian).
- **Reports**: Equipment Needs Summary, Equipment Consumption (issues counted once), Worker Custody,
  Repeat Equipment Requests.
- **Card Settings → Materials**: main store, tool custody store, repeat window.

## 5. Fixed — Verified

Found and fixed before release (unreleased code only; no published version affected):
- Approval failed for a Card Manager without an ERPNext stock/purchase role; it now uses the
  approver's own ERPNext rights and says what is missing.
- The operator page posted without CSRF validation; the session now gets its token on render.
- Two reports listed other projects' requests to a supervisor limited to one project; they now
  follow the user's record permissions.
- Earlier review fixes: escaped page values, approval fields not writable through REST, double
  approval race (row lock), custody cancel deleting only its own draft Stock Entry.

## 10. Known Limitations — Verified

- Material Requests and Stock Entries are drafts; ERPNext users submit them.
- CARD roles add to ERPNext permissions: approvers need e.g. Stock User / Purchase User;
  supervisors working in Desk need e.g. Projects User + Stock User to pick projects, warehouses and
  employees.
- A User linked to an Employee gets ERPNext's standard Employee role, which opens Desk. Operators
  can therefore open Desk, but see only their own requests (no equipment, stock or custody records).
- Equipment Consumption is not available to Card Supervisor (needs `report` on Card Equipment).
- Custody draft Stock Entries are created without the creator's stock rights (drafts only).
- Without the Card Equipment accounting dimension the flow works but rows carry no equipment.
- Published ≠ deployed: **not deployed to any production site**.

## 12. Installation & Upgrade — Partially Verified

- Upgrade from v3.0.0: `bench migrate` runs `v4_0_0.ensure_materials_roles` once (creates Card
  Supervisor and Card Operator; idempotent). No existing record is written. Verified on the dev
  site: migrate twice, no duplicates.
- Before use: create the Card Equipment accounting dimension if missing; choose the tool custody
  store and main store in Card Settings → Materials; link worker Users to Employees and give them
  Card Operator; give approvers and supervisors the companion ERPNext roles above.
- **Rehearse on a copy of production first.** Rollback = restore the pre-upgrade backup.
