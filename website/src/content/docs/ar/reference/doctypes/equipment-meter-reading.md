**Equipment Meter Reading**

| | |
|---|---|
| النوع | قابل للتقديم (مسودة ← مقدَّم ← ملغى) |
| الوحدة | Card |
| فتح في الواجهة | `/app/equipment-meter-reading` |


## الحقول

| التسمية | اسم الحقل | النوع | الخيارات / الربط | إلزامي |
|---|---|---|---|---|
| المعدات | `equipment` | Link | [المعدات](/card/ar/reference/doctypes/card-equipment/) | نعم |
| الشركة <small>(للقراءة فقط)</small> | `company` | Link | الشركة | نعم |
| تاريخ ووقت القراءة | `reading_datetime` | Datetime |  | نعم |
| ساعات تشغيل المحرك | `engine_hours` | Float |  | نعم |
| مصدر القراءة | `source` | Select | قراءة أسبوعية · قراءة عند التسليم · قراءة عند الصيانة · قراءة أخرى | نعم |
| القراءة السابقة <small>(للقراءة فقط)</small> | `previous_reading` | Data |  |  |
| ساعات المحرك في القراءة السابقة <small>(للقراءة فقط)</small> | `previous_engine_hours` | Float |  |  |
| تصفير العداد | `is_meter_reset` | Check |  |  |
| سبب التصفير | `reset_reason` | Small Text |  |  |
