## نظرة عامة

لا يحتفظ CARD **بسجل أصناف خاص به**؛ فقطع الغيار والمستهلكات والأدوات أصنافٌ (Items) قياسية في ERPNext، ويضيف CARD فوقها
ثلاثة أمور:

- **البحث في الكتالوج**، الذي يتيح للمشغلين والمشرفين إيجاد الصنف الصحيح بالاسم أو الرمز أو الباركود أو رقم القطعة الأصلي
  (OEM)، بصلاحيات المستخدم نفسه في ERPNext؛
- **توافق قطع الغيار**: سجلات موثقة ومراجَعة تثبت أن صنفًا يناسب موديل معدة أو معدة بعينها؛
- **التكلفة لكل معدة**: تحمل القطع المصروفة من المخزون ومشتريات الصيانة البُعدَ المحاسبي **Card Equipment**، فيكون لكل معدة
  تكلفة صيانتها في الدفتر الرسمي.

## المفاهيم الأساسية

| المفهوم | المعنى |
|---|---|
| ماركة المعدة / موديل المعدة | السجلان الرئيسيان **ماركة المعدة** (Card Equipment Make) و**موديل المعدة** (Card Equipment Model)؛ ويتبع الموديل ماركة واحدة ونوع معدة واحدًا. |
| صف التوافق | سجل **توافق قطع الغيار** (Card Equipment Part): صنف يناسب موديل معدة أو معدة بعينها، مع حالة توافق وإثبات. |
| التوافق الفعلي | توافق الصنف مع معدة واحدة، ويُحسب عند القراءة: صف المعدة نفسها يتقدم على صف موديلها. |
| المراجعة الثانية | لا يتخذ صاحب اقتراح الصف قراره النهائي أبدًا؛ بل يتخذه مراجع ثانٍ مستقل. |
| البُعد Card Equipment | البُعد المحاسبي الذي يضع المعدة على صفوف إدخال المخزون وطلبات المواد والفواتير. |

## المزايا

### البحث في الكتالوج

الكتالوج بحث واحد مقسّم إلى صفحات في كتالوج ERPNext القياسي: الصنف (Item)، ومجموعة الأصناف، والعلامة التجارية، وباركود
الصنف، ومصنّع الصنف (أرقام القطع الأصلية)، والصنف البديل. ويستخدمه منتقي الأصناف **تصفح الكتالوج** في CARD Mobile، وبحث
الأصناف في صفحة `/equipment-needs`؛ أما مدخل **الكتالوج** في الشريط الجانبي «المواد والمشتريات» فيفتح قائمة الأصناف في ERPNext.

- البحث بـ **اسم الصنف** أو **رمز الصنف** أو **الباركود** أو **رقم القطعة الأصلي** (الباركود وأرقام القطع من ثلاثة أحرف فأكثر).
- التصفية بـ **مجموعة الأصناف** (مع مجموعاتها الفرعية) و**العلامة التجارية**.
- تعرض كل نتيجة الصورة والوحدة والمجموعة والعلامة التجارية وأرقام القطع الأصلية والبدائل القياسية (بما فيها البدائل في
  الاتجاهين).
- تُقسم النتائج إلى صفحات على الخادم، ولا يُعرض عدد إجمالي، بل يُبين فقط ما إذا كانت هناك صفحة أخرى.
- عند اختيار معدة، يعرض كل صنف **توافقه مع تلك المعدة**، ويقصر خيار **يركب على هذه المعدة** القائمة على الأصناف المؤكدة لها.

لا يعيد الكتالوج أبدًا أي مخزون أو سعر أو مورد أو حساب.

ويقرر الخادم من يرى ماذا:

| المستخدم | الوصول إلى الكتالوج |
|---|---|
| الأدوار التي تقرأ الأصناف | قائمتهم المعتادة في ERPNext، مع صلاحيات المستخدم والمشاركات وقواعد الصلاحيات الخاصة بهم |
| Card Operator وCard Supervisor وCard Manager (أدوار البوابة) دون صلاحية قراءة الأصناف | الكتالوج نفسه على حقول آمنة ثابتة، مع تطبيق صلاحيات المستخدم على الصنف ومجموعة الأصناف والعلامة التجارية |
| Card User | مستعرض للكتالوج للقراءة فقط في CARD Mobile، بلا وصول إلى الطلبات |
| أي شخص آخر | لا شيء |

تُطبق قواعد الصلاحيات التي تسجلها التطبيقات الأخرى (مثل تقييد الأصناف بالشركة) كما تطبقها قائمة ERPNext نفسها. وإذا وُجد
سكربت خادم لاستعلام الصلاحيات، فإن القراءة المقيدة لا تعيد شيئًا.

### ماركات المعدات وموديلاتها

- **ماركة المعدة**: **اسم الماركة**، و**معطّلة**.
- **موديل المعدة**: **اسم الموديل**، و**ماركة المعدة**، و**نوع المعدة**، و**معطّل**، و**الوصف**.
- تُقارن الأسماء دون اعتبار لحالة الأحرف أو المسافات أو الشرطات أو النقاط أو الشرطات السفلية أو الخطوط المائلة، فـ«PC200-8»
  و«pc 200 8» اسم واحد، ويُرفض التكرار.
- في المعدة، يُعد الحقلان **ماركة المعدة** و**موديل المعدة** حقلين تجاريين (مستوى الصلاحية 1)، ويجب أن يطابق الموديل الماركة
  ونوع المعدة. وتبقى الماركة والموديل النصيان القديمان محفوظين.
- يعرض التقرير القرائي **قيم الماركة والموديل النصية** (Equipment Make Model Values) قيم الماركة والموديل النصية مع عدد
  معداتها، للمساعدة على ربطها بالسجلات الرئيسية (عامل التصفية «بدون موديل معدة فقط»).

### توافق قطع الغيار (Card Equipment Part)

يقرر صف التوافق (`CFP-#####`، مع تتبع التغييرات) أن صنفًا يناسب:

- **ينطبق على** = «موديل معدة»: كل معدة من ذلك الموديل (بلا شركة)، أو
- **ينطبق على** = «معدة»: معدة واحدة، ويأخذ الصف شركتها وموديلها.

الحقول:

- **صنف القطعة**: صنف مفعّل، ليس قالبًا ولم يتجاوز نهاية عمره.
- **حالة التوافق**: «قيد المراجعة الفنية» (عند الإنشاء)، أو «مؤكد»، أو «غير متوافق».
- **مرحلة المراجعة**: «بانتظار المراجعة الثانية» ما دامت مراجعة أولى تنتظر.
- **سبب القرار**، و**نشط**.
- **إثبات التوافق**: **مصدر الإثبات** (كتالوج قطع الغيار من المصنّع، أو كتالوج المصنّع أو الوكيل، أو تأكيد المورد أو الوكيل، أو
  فحص فعلي على المعدة، أو سجل تركيب، أو غير ذلك)، و**مرجع الإثبات**، و**ملف الإثبات** (ملف خاص بصيغة JPEG أو PNG أو WebP أو
  PDF لهذا الصف)، و**الكمية لكل استخدام**، و**ملاحظات فنية**.
- **سجل المراجعة** (يكتبه الخادم): من اقترح ومتى، ومن أجرى المراجعة الأولى ومتى وقرارها وسببها، ومن قرر ومتى، ومن أوقف الصف
  ومتى، وسبب الإيقاف، والمصدر.

القواعد:

- صف واحد لكل صنف وموديل، أو لكل صنف ومعدة. وإذا وُجد صف موقوف مكرر فيجب إعادة تفعيله بدلًا من إنشاء جديد.
- لا يتغير صنف الصف ونطاقه وموديله ومعدته بعد الإنشاء أبدًا.
- صفوف التوافق **تُوقف ولا تُحذف أبدًا**. ويحتاج الإيقاف إلى سبب، وإعادة التفعيل تعيد الصف إلى المراجعة.

### مراجعة التوافق

| من | ما يحق له |
|---|---|
| Card Supervisor | اقتراح الصفوف وتوثيق صفوفه ما دامت قيد المراجعة، دون ضبط الحالة أبدًا |
| Card Manager / System Manager (صاحب الاقتراح) | قراره في اقتراحه **مراجعة أولى** فقط: يحتاج سببًا جديدًا وملف إثبات، وينتظر الصف بحالة «بانتظار المراجعة الثانية» |
| Card Manager / System Manager (شخص آخر) | اتخاذ القرار النهائي («مؤكد» أو «غير متوافق»)، أو إعادة المراجعة الأولى مع سبب |

- يحتاج القرار إلى **مصدر الإثبات** و**مرجعه**.
- أي إثبات جديد على صف مقرَّر، من أي شخص، يعيده إلى «قيد المراجعة الفنية».
- لا يجوز تأكيد معدة مقابل صف «غير متوافق» لموديلها إلا مع ملاحظات فنية تشرح الاستثناء.
- لا يُستثنى أي دور من قاعدة الشخص الثاني، ولا حتى Administrator.

### حالات التوافق

عند اختيار معدة، يكون لكل صنف حالة واحدة من خمس حالات منفصلة:

| الحالة | المعنى |
|---|---|
| «مؤكد للمعدة» | صف «مؤكد» نشط على هذه المعدة |
| «مؤكد للموديل» | صف «مؤكد» نشط على موديل المعدة، لا يلغيه صف للمعدة |
| «غير متوافق» | صف «غير متوافق»، ويُعرض مع تحذير |
| «قيد المراجعة» | صف ما زال قيد المراجعة، ولا يُعد توافقًا أبدًا |
| «لا يوجد سجل توافق» | لا يوجد صف مطلقًا |

تحفظ طلبات احتياجات المعدات الحالة التي كانت لكل بند عند طلبه، ويحتاج البند الذي ليس له توافق مؤكد إلى **سبب صنف بدون
توافق مؤكد** (انظر [احتياجات المعدات](/card/ar/features/equipment-needs/)).

### المخزون المصروف للمعدات

لا تصل تكلفة القطعة إلى المعدة إلا عند صرفها لها من المخزون:

1. تنشئ مراجعة احتياجات المعدات المعتمدة **طلب مواد** (Material Request) مسودة من نوع «صرف مواد» (Material Issue) للقطع من
   المخزن، أو «شراء» (Purchase) للقطع المراد شراؤها، مع الصنف والمشروع ومركز التكلفة والمستودع، والبُعد **Card Equipment**
   على كل صف للقطع.
2. يصرف فريق المخزون القطعة بـ **إدخال مخزون** (Stock Entry) قياسي في ERPNext من نوع «صرف مواد»، وتحتفظ صفوفه بالمشروع ومركز
   التكلفة والمعدة.
3. يُرحَّل الصرف في ERPNext وفق إعدادات المخزون للشركة، ولا يكتب CARD شيئًا.

ويسرد التقرير القرائي **استهلاك المعدات** (Equipment Consumption) ما صُرف لكل معدة (صفوف صرف المواد المعتمدة)، إضافة إلى
الأصناف غير المخزنية المشتراة لها.

### تكلفة صيانة المعدات

يسرد التقرير القرائي **تكلفة صيانة المعدات** (Equipment Maintenance Cost)، المتاح لـ System Manager وAccounts Manager (مع
صلاحية دفتر الأستاذ العام)، صفًا لكل بند مستند موسوم بمعدة عبر البُعد Card Equipment، لشركة واحدة وفترة واحدة:

- بنود **فواتير الشراء** المعتمدة، باستثناء الفواتير التي تثبت كروت CARD أو تعبئات الديزل أو عمليات النقل، وبنود الأصول
  الثابتة، وبنود الأصناف المخزنية (التي تُحتسب عند صرفها)؛
- بنود **صرف المواد** المعتمدة في إدخال المخزون بقيمة تقييمها.

عوامل التصفية: **الشركة**، و**من تاريخ**، و**إلى تاريخ**، و**المشروع**، و**المعدة**. ومن دون البُعد يشرح التقرير ذلك ولا يسرد
شيئًا. والبنود نفسها تغذي جزء الصيانة في تقرير **الهامش الجزئي للمعدات**.

## سير العمل

1. أنشئ ماركات المعدات وموديلاتها، ثم اضبط الماركة والموديل على كل معدة.
2. يقترح المشرف صفوف التوافق مع الإثبات، ويؤكدها Card Manager أو يرفضها (ومدير ثانٍ إذا كان الأول هو صاحب الاقتراح).
3. يجد المشغلون الأصناف في الكتالوج، مع إظهار التوافق لمعدتهم، ويطلبونها عبر احتياجات المعدات.
4. بعد الاعتماد، يصرف فريق المخزون القطع بإدخال مخزون يحمل المعدة.
5. تابع التكلفة لكل معدة في **تكلفة صيانة المعدات** و**استهلاك المعدات**.

## الصلاحيات

| البند | الأدوار |
|---|---|
| ماركات المعدات وموديلاتها (إنشاء وكتابة) | System Manager وCard Manager |
| ماركات المعدات وموديلاتها (قراءة) | Card Supervisor وCard User وAccounts Manager |
| صفوف التوافق (إنشاء وكتابة) | System Manager وCard Manager وCard Supervisor (صفوفه قيد المراجعة) |
| قرارات التوافق والإيقاف وإعادة التفعيل | Card Manager وSystem Manager |
| قيم الماركة والموديل النصية | System Manager وCard Manager |
| تكلفة صيانة المعدات | System Manager وAccounts Manager |
| استهلاك المعدات | System Manager وCard Manager وCard Supervisor وCard User وStock Manager وAccounts Manager |

صف التوافق الخاص بمعدة يتبع شركة تلك المعدة، والمستخدم المقيّد ببعض الشركات لا يرى إلا صفوف معدات تلك الشركات (أما صفوف
الموديل فبيانات فنية مشتركة).
