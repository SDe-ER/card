تُولَّد هذه الصفحة من الشيفرة المصدرية لـ CARD في كل عملية بناء. عدّل الشيفرة لا هذه الصفحة.
:::

**Card Type Consumption Rate**

| | |
|---|---|
| النوع | جدول فرعي (صفوف داخل مستند آخر) |
| الوحدة | Card |


## الحقول

| التسمية | اسم الحقل | النوع | الخيارات / الربط | إلزامي |
|---|---|---|---|---|
| شركة معدل الاستهلاك | `company` | Link | الشركة |  |
| معدل الاستهلاك ساري من | `valid_from` | Date |  | نعم |
| معدل الاستهلاك (لتر في الساعة) | `litres_per_hour` | Float |  | نعم |
| سبب معدل الاستهلاك | `reason` | Small Text |  |  |


## الصلاحيات

لا صلاحيات مستقلة: يتبع الوصول المستند الأب.
