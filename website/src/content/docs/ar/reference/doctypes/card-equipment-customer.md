تُولَّد هذه الصفحة من الشيفرة المصدرية لـ CARD في كل عملية بناء. عدّل الشيفرة لا هذه الصفحة.
:::

**Card Equipment Customer**

| | |
|---|---|
| النوع | مستند |
| الوحدة | Card |
| فتح في الواجهة | `/app/card-equipment-customer` |


## الحقول

| التسمية | اسم الحقل | النوع | الخيارات / الربط | إلزامي |
|---|---|---|---|---|
| العميل | `customer` | Link | العميل | نعم |
| اسم العميل <small>(للقراءة فقط)</small> | `customer_name` | Data |  |  |
| أول شهر تشغيل <small>(مخفي, للقراءة فقط)</small> | `first_month` | Data |  |  |
| آخر شهر تشغيل <small>(مخفي, للقراءة فقط)</small> | `last_month` | Data |  |  |


**الإحصاءات**

| التسمية | اسم الحقل | النوع | الخيارات / الربط | إلزامي |
|---|---|---|---|---|
| عدد المعدات <small>(مخفي, للقراءة فقط)</small> | `equipment_count` | Int |  |  |
| عدد الكروت المعتمدة <small>(مخفي, للقراءة فقط)</small> | `card_count` | Int |  |  |
| إجمالي الساعات <small>(مخفي, للقراءة فقط)</small> | `total_hours` | Float |  |  |
| إجمالي المستحق (من الكروت) <small>(مخفي, للقراءة فقط)</small> | `total_accrued` | Currency |  |  |
| آخر تحديث <small>(مخفي, للقراءة فقط)</small> | `last_refreshed` | Datetime |  |  |

| الدور | الحقوق |

| مدير الكروت | قراءة, كتابة, إنشاء, تقرير, تصدير, طباعة, بريد |
| مستخدم الكروت | قراءة, تقرير, طباعة, بريد |
