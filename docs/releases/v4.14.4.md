## 3. Added — Partially Verified

- **Desk buttons on a submitted customer Sales Invoice (PR #355, FR-194, FR-195).** The group `Card` shows **Link to
  monthly cards** to an Accounts Manager or a System Manager when the invoice is not linked. A System Manager also sees
  **Remove link to monthly cards** on an invoice that a person linked. The link dialog lists the unlinked approved cards
  of the customer on the invoice projects, shows the invoice net and the selected total, and asks for a reason. The
  buttons call `link_customer_invoice` and `unlink_customer_invoice`, which keep every check and every audit comment.
- **`card.gl.integrity.customer_invoice_link_info` (GET).** Gives the dialog the link state and the cards, with the gates
  of the candidates list. It writes nothing.
- Verified by CI tests. Screenshots are in the pull request. Not checked on a real Desk by the Owner yet.

## 4. Improved — Partially Verified

- **The application name is `Card` in every language (PR #372, Owner decision 2026-11-28, WS-024).** `app_title`, the two
  apps-screen titles (`Card`, `Card Mobile`), the Card Mobile page titles and manifest, the Monthly Posting page title
  and every user-facing message that named the application read `Card`. Record names, routes (`/app/card`, `/cdms`),
  DocType, role and field names, the literal tax template name `CARD VAT <rate>% - <abbr>`, the workspace and report
  names that end with `(CARD)` and the Select value `All CARD approvals` are stored data and do not change. Display only.

## 12. Installation & Upgrade — Partially Verified

- **Upgrade from v4.14.3:** new code; `bench --site <site> migrate`; `bench build --app card`; `bench --site <site> clear-cache`;
  restart. The build is needed because `card/public/js/customer_invoice_link.js` and `frontend/` changed. Rebuild the
  compiled translations: the name change reaches a site only with them.
- **What migrate writes:** the patch `v4_1_3.remove_app_name_translations` is already recorded on a site that ran it, so
  it does not run again. **It does not write:** any column, document, amount, GL entry, role or permission.
- **Post-deployment acceptance (owner):** reload the Desk. Open a submitted customer Sales Invoice as an Accounts
  Manager and check the group `Card`. Check that the apps screen shows `Card` in English and in Arabic.
- **Safe rollback — Verified from source; not runtime-tested.** Code only, to v4.14.3, then `bench build --app card` and
  compile the locale files again. No data step. v4.14.4 writes no new field, state or record type.
