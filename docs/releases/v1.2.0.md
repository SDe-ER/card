## 1. Version Overview

The release that turns CARD from a supplier monthly-card tracker into a full equipment rental and
operations product: rental directions (in/out/sub-rental/owned) with a customer side, per-company
settings and roles, diesel and transport management, three rate bases, the Card Equipment
accounting dimension, opt-in monthly draft invoice posting with an audit log, nine reports,
professional RTL print formats and a complete Arabic translation over an English source UI.

## 3. Added — Verified (CHANGELOG `[1.2.0]`, PRs above)

- English-source UI + full Arabic translation (v1.1 line); Desk connections between equipment,
  cards, suppliers, customers, projects; workspace/sidebar polish; per-shift hour heatmaps.
- Card Settings + Card Company Settings; Card Manager / Card User roles; permission levels.
- Rental directions on the equipment (rented-in, rented-out, sub-rental, owned) with hours-only
  monthly cards; customer registry; Equipment Customer Statement / Customers Summary on official
  receivables.
- Three rate bases (hourly, daily, monthly) — all bill operating hours.
- Diesel & transport: Project Diesel Fill with project-tank allocation by operating hours,
  Equipment Transport with per-project prices, diesel supplier policy, four cost/diesel reports.
- Card Equipment accounting dimension, guard report Equipment Expenses Without Equipment, period
  lock, equipment transfers with assignment tracking, RTL print formats.
- Monthly supplier/customer postings (opt-in per company) with GL Posting Log — documents are
  always created as **drafts** for accountant review.
- CI: clean-site tests, linters, CodeQL, Semgrep; Dependabot (PR #5).

## 4. Improved — Verified

- Repository presentation, copyright headers, README (PR #1).

## 5. Fixed — Verified

- **Report access** (#13 / PR #14): all nine reports run for one validated company; ledger figures
  shown only to users whose roles read GL Entry; link filters use CARD-owned queries.
- **Diesel allocation** requires a company and scopes fills and hour weights to it (PR #14).
- **Workspace number cards** no longer pin SAR (#15 / PR #16).
- **Arabic labels** for GL Posting Log fields (#17 / PR #18).

None.

## 7. Replaced

None at this tag. (The internal link-query endpoints `card.api.card_projects_query` /
`card.api.card_companies_query` introduced here were **replaced in v1.2.1** — see that page.)

## 8. Simplified — Verified

- Card entry became **hours-only**: equipment, shift, month, year and driver; everything else
  (project, company, direction, parties, rates) flows in automatically and sits in a collapsed
  info section. Old flow: manual entry of rate/party context per card.

## 9. Breaking Changes — Verified

- **Company is a required report filter** (defaults to the user's company).
- *Equipment Expenses Without Equipment* is limited to System Manager and Accounts Manager.
- Report ledger columns now require a role that reads GL Entry (an operational user no longer sees
  ledger balances).
- Tested on Frappe/ERPNext **16.50+ only** — earlier v16 minors are no longer validated.

## 10. Known Limitations — Verified

- **Never deployed to any production site by this release**; a rehearsal of v1.0.1 → v1.2.0 on a
  copy of production data is required first.
- Broader accounting phases (per-company activation workflow, tax classes, claims, allocation
  shares) are an approved design, **not** in this release.
- Some Arabic labels come from Frappe/ERPNext core translations (adjustable per site).
- Multi-company registry totals are **not** isolated per company (found later, #23 — fixed in
  v1.2.2). Operational roles could not run reports filtered by supplier/customer/project
  (#21 — fixed in v1.2.1).

## 12. Installation & Upgrade — Verified

- From v1.0.1: back up, then `bench --site <site> migrate`. Eleven v1.2 patches run once
  (`ensure_card_roles`, `backfill_snapshot`, `init_card_settings_defaults`,
  `set_operator_fuel_defaults`, `init_shift_limits`, `backfill_card_direction`,
  `backfill_rental_direction`, `rederive_draft_cards`, `backfill_adjustment_side`,
  `ensure_print_defaults`, `recompute_posting_keys`).
- **Accounting stays off** after upgrade until enabled per company in Card Settings. Assign Card
  Manager / Card User to operational users; ledger-column viewers need a GL-Entry-reading role.
- Multi-company sites: list projects whose cards or diesel fills span companies before upgrading
  (diesel allocation becomes per-company).
