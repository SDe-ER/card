# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in CARD, please report it **privately** by email to:

**info@sdce.sa**

Please do **not** open a public GitHub issue for security problems.

Include, where possible:

- a description of the vulnerability and its impact,
- steps to reproduce (with **invented/demo data only** — never real company, supplier, operator or financial data),
- the affected version (`card` version from `bench version`) and the Frappe/ERPNext versions.

We will acknowledge your report, investigate, and coordinate a fix and disclosure timeline with you.

## Supported versions

Security fixes target the latest released version of CARD on the supported Frappe line (**≥ 16.50**). Please upgrade to the latest release before reporting.
