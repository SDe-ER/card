# CARD v4.2.1 — 2026-10-27

> Patch release on top of v4.2.0: a simpler diesel fill form. Layout only; no patch, no new column.
> Labels: **Verified / Partially Verified / Unknown / Not Supported / Deprecated / Removed**.

## 1. Version Overview

The `Project Diesel Fill` form opens with the fill (date, project, supplier), the **Meter readings** (photos and
readings, then the litres) and the **Equipment filled**. The price shows on one line. The evidence check, the
operations review, the meter details, the price exception, the import source and the cost center / posting links
show only when they are relevant or stay collapsed. The company is filled and hidden for a user with one company.
