## 5. Fixed — Partially Verified

- **Issue 324 — the customer statement PDF joins Arabic letters.** The PDF action used the standard report route
  (wkhtmltopdf), which drew the letter alef apart from the letter before it in some words. It now uses a server
  route with the Chrome PDF generator, as the Equipment Supplier Statement does since v4.4.3. Verified by CI tests
  (the HTML given to the generator); the produced PDF was not seen on a real Desk before the release.

## 10. Known Limitations — Verified

- The choices of the PDF dialog (letter head, orientation, columns, another print format) do not apply to the
  statement PDF: the page is a fixed A4 statement. The supplier statement behaves the same way.
- A saved custom copy of the report under another name keeps the standard PDF route.
- The site needs the Chrome PDF generator that the CARD print formats already use.
- Everything listed for v4.12.1 that this page does not change.
