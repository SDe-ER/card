# CARD v1.0.1 — 2026-10-13

> Frappe 16.51 compatibility hotfix on top of v1.0.0. Tag
> [`v1.0.1`](https://github.com/SDe-ER/card/releases/tag/v1.0.1) (commit `8118c6fd`).
> Labels: **Verified / Partially Verified / Unknown / Not Supported / Deprecated / Removed**.

## 1. Version Overview

No functional change to the monthly-card workflow. This release exists so that `bench migrate`
succeeds on Frappe ≥ 16.51 and so the 16.50 desk Sidebar carries the curated Card items. It is the
version that was **deployed to SDCE production on 2026-10-13** (image `erp-v16:card-v1.0.1-20261013`,
digest `sha256:146b7001…cdd6` — Verified from the GitHub release notes).

## 2. Complete Feature Inventory — Verified

Identical surface to [v1.0.0](v1.0.0.md): 8 DocTypes, 2 supplier reports, Card workspace + desktop
icon, Arabic monthly print format, idempotent installer. Patches: 6 entries (4 from v1.0.0 + 2 new).

## 3. Added — Verified

- Patch `card.patches.v1_0_1.fold_sidebar_and_retire_legacy_module` (runs inside a DB savepoint so
  the cosmetic fold can never abort `bench migrate`).

## 4. Improved

- Packaged `__version__` aligned to `1.0.1` (was `0.0.1` at v1.0.0).

## 5. Fixed — Verified

- **Workspace fixture `module`** was empty; Frappe ≥ 16.51 makes `Workspace.module` mandatory, so
  `bench migrate` failed in `sync_fixtures` (`MandatoryError [Workspace, Card]: module`). The Card
  Workspace and the five `Card Monthly Card *-in_list_view` Property Setters now carry
  `module: "Card"`.
- **Frappe 16.50 `Sidebar` fold:** the desk-navigation `Sidebar` the upgrade built as
  `Card (Custom)` is folded into the canonical `Sidebar` name `Card` / module `Card`, keeping all
  items.
- **`net_amount` backfill** for cards submitted before v1.0
  (`net_amount = amount + total_additions − total_deductions`; field-only `db_set`, no re-submit,
  no GL impact).

## 6. Removed — Verified

- **Legacy `Card (Custom)` Module Def** is retired idempotently (reassign → `Card`, then delete
  only when unreferenced; never force-deleted).

## 7. Replaced / 8. Simplified

None recorded.

## 9. Breaking Changes

None. No field removed or renamed; no behaviour change to cards or reports.

## 10. Known Limitations — Verified

- All v1.0.0 functional limits remain (no accounting posting, no customer side, no i18n, single
  legacy print format). The legacy print format keeps pre-existing wkhtmltopdf layout defects
  (documented later in v1.2.1 notes).

## 11. Compatibility — Verified

| Requirement | Value |
|---|---|
| Frappe / ERPNext | v16 **including 16.51.1 / 16.50.0** (validated on 16.33.0, 16.36.1 and the 16.51 production upgrade) |
| Python | ≥ 3.14 |
| Required apps | `erpnext` only |

## 12. Installation & Upgrade — Verified

- From v1.0.0: `bench --site <site> migrate` (two new idempotent patches; the Sidebar fold is
  non-fatal by design).
- Fresh install: as v1.0.0 (`install-app card`, `--force` on a legacy site).
- Source tarball SHA256 (`git archive --format=tar.gz --prefix=card/ v1.0.1`):
  `1abc04ad5228384b812f2b20ca5f26701262b78b58a34bc6a648c81005aa8730`.

## 13. Recommended For

- Sites on **Frappe v16 minors below 16.50** that only need the original supplier monthly-card
  workflow: this is the last version validated on 16.33/16.36. (v1.2.x is tested on 16.5x only —
  earlier minors are **Unknown** there.)
- Sites that must match the version **verified deployed on SDCE production** (2026-10-13).
