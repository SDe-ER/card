Use `<category>/<design>/<revision>/`. Each delivered revision contains sources,
assets, PDF, previews, instructions and validation evidence. See
[the template policy](../AGENTS.md) before adding a design.

Only the latest delivered operation-card design is imported here. Earlier iterations
remain in the originating work session; they are not represented as uploaded revisions.
