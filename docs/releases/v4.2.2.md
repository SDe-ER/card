# CARD v4.2.2 — 2026-10-27

> Patch release on top of v4.2.1: the diesel meter photos are shown large on the fill form, and the reading labels
> name the fill meter. Form script and translations only; no patch, no column, no DocType change.
> Labels: **Verified / Partially Verified / Unknown / Not Supported / Deprecated / Removed**.

## 1. Version Overview

On the `Project Diesel Fill` form, each meter photo (opening and closing) shows as a card in place of the file link,
full width up to 480 px high, so the meter can be read without opening the file. A click opens the full photo. On an
editable fill the card has the control's own change (image uploader) and remove (with its confirmation) buttons. The
Arabic labels of the two readings now name the fill meter (reset at each fill), not the totalizer.
