# CARD templates

The [document design library](documents/README.md) is the required repository home for
all new or revised printable designs: operation cards, invoices, receipts, account
statements, diesel reports and other documents.

Keep editable sources, assets, PDF, previews and validation together in a versioned
folder. See [template instructions](AGENTS.md).

Existing `pages/`, Python files, runtime Jinja templates and Print Format fixtures are
application infrastructure. This library does not replace or relocate them and does
not register, install or deploy any Print Format.
